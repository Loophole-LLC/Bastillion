Certificate Authorities

Bastillion's own certificate authority — the key you install on each system so it will accept Bastillion's certificates — lives with the application key under Settings, since both are about what Bastillion presents to a host. This screen is the other direction: what hosts present to us.

Trusted host certificate authorities

A system presenting a host certificate signed by one of these is accepted without its own host key needing to be recorded or approved above - useful for a fleet that is reprovisioned often.
